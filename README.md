# interior-studio-portal

A polished, responsive landing page for an interior studio brand called Aurelia Studio.

## Features
- Hero section with premium editorial design
- Portfolio showcase for residential and boutique interiors
- Services, process, testimonial, and contact sections
- Mobile-friendly navigation
- Elegant responsive styling

## Open locally
Open `index.html` directly in a browser, or run a simple local server from the project folder:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — page structure and content
- `styles.css` — design system, layout, and responsiveness
- `script.js` — mobile menu and contact form interaction
